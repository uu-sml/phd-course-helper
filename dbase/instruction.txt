i want you to add this {school/course} in {school/course}.json on the same
format as the others, that is
{
      "year":
      "semester": {SPRING/SUMMER/FALL/WINTER}
      "code":
      "credits":
      "title": {title [x credits]}
      "url":
      "description":
      "when":
      "where":
      "contact":
}.
if you find no credit information, don't add this to the title. if you dont find
enough description, feel free to elaborate a little on the theme of the course
to make the description more appealing, but keep it rather brief.

the "description" field should be ONLY a short summary of the course content
(no dates, location, examination/assessment details, or registration info -
those either live in their own fields or are left out). think of it as a PRIMER
that sparks interest and makes the reader want to click the link to read more,
NOT an exhaustive syllabus. when the entry has a "url" with more info (the usual
case), keep it to just a few sentences: a one-line framing of what the course is
about plus a short, representative sample of topics (not every topic covered).
for example, this is a good length and style:
  "Introduction to robust linear multivariable control, covering feedback
   limitations, stability/performance under uncertainty, H2/H∞ methods,
   μ-synthesis, loop shaping, and LMIs."
only go longer if there is no link where the reader can find out more.

the "url" field should point to the course's own information page - a syllabus
page, a course-plan or course-description document (e.g. a shared Google Doc),
or similar - i.e. where a reader learns what the course is about. do NOT use the
registration page (e.g. a KURT/medfarm link) as the url; that belongs in the
"contact" field. only if a registration page is the sole link available may it
serve as the url.

the "when" field is when the course is expected to be given, on the format
{Month - Month year} (no exact days unless that is the only info available, e.g.
a single start date). if you cannot find this, omit the field.

the "where" field is where the course is given, typically the university (and
city if relevant). if you cannot find this, omit the field.

the "contact" field is who to contact and/or where and how to sign up, if that
info is necessary or included (e.g. a course responsible, a registration email,
or the registration link itself - a KURT/medfarm page belongs here, not in the
"url" field). if a registration deadline is given, include it here too. if there
is no such info, omit the field. any link in this field must be a real HTML
anchor tag, not a raw pasted URL - the field is rendered as HTML, so write e.g.
Register <a href=\"https://...\" target=\"_blank\">here</a> by <deadline>
rather than pasting the bare url.

all three of "when", "where" and "contact" are optional - only include a field
if you have the information for it. the site renders each present field on its
own line with a bold label (Description:, When?, Where?, Sign-up / contact:).
